Endorsement grid patterns

Reference for the homepage endorsement grid. Each pattern is just classes on the tiles in index.html; the CSS is identical to the live site. Rule of thumb: a feature tile is 4 cells, the “read more” tile is 2, everything else is 1. Keep each section to a multiple of 4 so rows end flush.

A. Lead feature (live now)

One is-feature tile up front, singles fill in order. The 2-wide “read more” tile squares off the last row; drop it when the singles alone come out even.
